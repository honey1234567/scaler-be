# 🟦 4. Best Production Implementation (Using **BlockingQueue**)

This is **ideal for interviews + production**.

## Shared Buffer

```java
public class BlockingQueueBuffer {

    private final BlockingQueue<Item> queue;

    public BlockingQueueBuffer(int capacity) {
        this.queue = new ArrayBlockingQueue<>(capacity);
    }

    public void put(Item item) throws InterruptedException {
        queue.put(item); // blocks if full
    }

    public Item take() throws InterruptedException {
        return queue.take(); // blocks if empty
    }
}
```

---

## Producer

```java
public class Producer implements Runnable {

    private final BlockingQueueBuffer buffer;

    public Producer(BlockingQueueBuffer buffer) {
        this.buffer = buffer;
    }

    @Override
    public void run() {
        int value = 0;
        try {
            while (true) {
                Item item = new Item(value++);
                buffer.put(item);
                System.out.println("Produced: " + item);
                Thread.sleep(500);
            }
        } catch (InterruptedException ignored) {}
    }
}
```

---

## Consumer

```java
public class Consumer implements Runnable {

    private final BlockingQueueBuffer buffer;

    public Consumer(BlockingQueueBuffer buffer) {
        this.buffer = buffer;
    }

    @Override
    public void run() {
        try {
            while (true) {
                Item item = buffer.take();
                System.out.println("Consumed: " + item);
                Thread.sleep(1000);
            }
        } catch (InterruptedException ignored) {}
    }
}
```

# 🧵 7. Concurrency Explained — BlockingQueue Internals

`ArrayBlockingQueue` uses:

### **1. ReentrantLock**

* Protects entire queue
* Ensures only one thread modifies queue at a time

### **2. Conditions**

* `notEmpty.await()` → consumer waits when queue is empty
* `notFull.await()` → producer waits when queue is full

### **3. No Busy Waiting**

Threads sleep until they get a signal.

# 🟥 8. Alternative #2 — Custom Producer-Consumer using `wait()` and `notifyAll()`

This is often asked in interviews to check OS concepts.

---

## Custom Shared Buffer (Manual locking)

```java
public class WaitNotifyBuffer {

    private final Queue<Item> queue = new LinkedList<>();
    private final int capacity;

    public WaitNotifyBuffer(int capacity) {
        this.capacity = capacity;
    }

    public synchronized void put(Item item) throws InterruptedException {
        while (queue.size() == capacity) {
            wait();
        }
        queue.add(item);
        notifyAll();  // wake consumer
    }

    public synchronized Item take() throws InterruptedException {
        while (queue.isEmpty()) {
            wait();
        }
        Item item = queue.poll();
        notifyAll();  // wake producer
        return item;
    }
}
```

### **Concurrency Tools Used:**

| Tool           | Why Used                                  |
| -------------- | ----------------------------------------- |
| `synchronized` | mutual exclusion on buffer                |
| `wait()`       | block thread until condition becomes true |
| `notifyAll()`  | wake both producers/consumers             |

# 🟪 Alternative #3 — **Semaphore-based Implementation (Advanced)**

Used to teach OS fundamentals.

---

## Code

```java
public class SemaphoreBuffer {

    private final Queue<Item> queue = new LinkedList<>();
    private final Semaphore empty;
    private final Semaphore full;
    private final Semaphore mutex = new Semaphore(1);

    public SemaphoreBuffer(int capacity) {
        empty = new Semaphore(capacity);
        full = new Semaphore(0);
    }

    public void put(Item item) throws InterruptedException {
        empty.acquire();
        mutex.acquire();

        queue.add(item);

        mutex.release();
        full.release();
    }

    public Item take() throws InterruptedException {
        full.acquire();
        mutex.acquire();

        Item item = queue.poll();

        mutex.release();
        empty.release();

        return item;
    }
}
```

### Semaphores Used:

| Semaphore | Purpose                  |
| --------- | ------------------------ |
| `empty`   | Tracks empty slots       |
| `full`    | Tracks filled slots      |
| `mutex`   | Ensures mutual exclusion |
